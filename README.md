# Museo Interactivo Zacatecas

## Requisitos Previos
Instalar **LÖVE 2D** desde: [love2d.org](https://love2d.org/)

## ¿Cómo ejecutar el juego?

**Opción 1:** Arrastra la carpeta de este proyecto y suéltala sobre el archivo `love.exe` (usualmente en `C:\Program Files\LOVE`).

**Opción 2:** Desde la terminal, dentro de la carpeta del proyecto ejecuta:
```powershell
"C:\Program Files\LOVE\love.exe" .
```
